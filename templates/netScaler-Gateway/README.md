NetScaler Monitoring
====================

[![Static Badge](https://img.shields.io/badge/DOWNLOAD-.cfg-blue?style=for-the-badge&color=B071DC)](https://github.com/sentrysoftware/studioX-templates/raw/refs/heads/master/templates/netScaler-Gateway/netscaler.cfg) [![Static Badge](https://img.shields.io/badge/-_GET_SUPPORT-blue?style=for-the-badge&color=004577)](https://www.sentrysoftware.com/about/index.html#section-contact)

> [!CAUTION]
> No support is provided for this template unless purchased. Refer to [Support for Monitoring Studio X Templates](../../support.md) for more details.

Provides monitoring of NetScaler Appliance:

* Cluster
* High Availability
* System Resources
* Service Groups
* VLAN Statistics
* VServer

Add the NetScaler Appliance under the hosts tab and define the system type as 'Other' and provide appropriate SNMP Community String or User Credentials depending on the SNMP protocol version.
