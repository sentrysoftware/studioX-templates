VEEAM Backup
============

[![Static Badge](https://img.shields.io/badge/DOWNLOAD-.cfg-blue?style=for-the-badge&color=B071DC)](https://github.com/sentrysoftware/studioX-templates/raw/refs/heads/master/templates/veeam-Backup/veeamBackup.cfg) [![Static Badge](https://img.shields.io/badge/-GET_SUPPORT-blue?style=for-the-badge&color=004577)](https://www.sentrysoftware.com/about/index.html#section-contact)

Provides monitoring of:

* Agent Backup Jobs
* License
* Proxy Details
* Repository Details
* Processes
* Services
* Events

The templates executes a Power Shell script to pull the details of backup jobs, repositories and proxies.
Ensure that the user account used for monitoring has access to execute the script.

* Add the VEEAM Backup Server host under the hosts tab and define the system type as Windows.
* Provide appropriate user credentials to access the server.
* Activate the VEEAM template and click on Create.
