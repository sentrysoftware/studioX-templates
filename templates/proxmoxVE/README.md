Proxmox VE Monitoring
====================

[![Static Badge](https://img.shields.io/badge/DOWNLOAD-.cfg-blue?style=for-the-badge&color=B071DC)](https://github.com/sentrysoftware/studioX-templates/raw/refs/heads/master/templates/proxmoxVE/proxmoxVe.cfg) [![Static Badge](https://img.shields.io/badge/-_GET_SUPPORT-blue?style=for-the-badge&color=004577)](https://www.sentrysoftware.com/about/index.html#section-contact)

> [!CAUTION]
> No support is provided for this template unless purchased. Refer to [Support for Monitoring Studio X Templates](../../support.md) for more details.

Provides monitoring of the Proxmox VE:

* Performance
* Daemons
* QMs status
* Datastore performance and status

The template uses the Proxmox VE CLI.

* Add the Proxmox host under the hosts tab and define the system type as `Linux/Unix`.
* Provide appropriate username and password to execute Proxmox commands.
