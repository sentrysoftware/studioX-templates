SKYPE for Business
==================

[![Static Badge](https://img.shields.io/badge/DOWNLOAD-.cfg-blue?style=for-the-badge&color=B071DC)](https://github.com/sentrysoftware/studioX-templates/raw/refs/heads/master/templates/microsoft-skype/skype.cfg) [![Static Badge](https://img.shields.io/badge/-GET_SUPPORT-blue?style=for-the-badge&color=004577)](https://www.sentrysoftware.com/about/index.html#section-contact)

> [!CAUTION]
> No support is provided for this template unless purchased. Refer to [Support for Monitoring Studio X Templates](../../support.md) for more details.

Provides monitoring of:

* Application
* Archiving
* Central Management
* Conferencing
* Core
* Edge
* Monitoring
* Provisioning
* Registration
* User
* Web
The templates uses Windows Performance Counters, Windows Events and Windows Service monitoring features.

* Add the SKYPE server under the hosts tab and define the system type as Windows.
* Provide appropriate user credentials to access the server.
* Set the value of the macro `PATH` with the installation path of the Skype for Business Server.
